    What is Akati OS?Akati OS คืออะไรAkati OS là gì?Apa itu Akati OS?

    Akati OS is a free gaming playbook for AME Wizard. A playbook is a package of scripts and settings that AME Wizard applies to an installed copy of Windows. Akati OS turns off things most gaming PCs do not need, tunes settings for games and adds Akati OS Center, one app for Game boost, health checks, gaming apps, tweaks and the look of Windows, in English, Thai, Vietnamese and Indonesian.

    Akati OS คือ playbook สำหรับเล่นเกมที่ใช้กับ AME Wizard ได้ฟรี playbook คือชุดสคริปต์และการตั้งค่าที่ AME Wizard นำไปปรับใช้กับ Windows ที่ติดตั้งอยู่ Akati OS ปิดสิ่งที่เครื่องเล่นเกมส่วนใหญ่ไม่ได้ใช้ ปรับค่าให้เหมาะกับเกม และเพิ่ม Akati OS Center แอปเดียวที่รวมบูสต์เกม ตรวจสุขภาพเครื่อง แอปเกม การปรับแต่ง และหน้าตา Windows ไว้ด้วยกัน มีภาษาอังกฤษ ไทย เวียดนาม และอินโดนีเซีย

    Akati OS là playbook chơi game miễn phí cho AME Wizard. Playbook là một gói script và cài đặt mà AME Wizard áp dụng lên bản Windows đã cài. Akati OS tắt những thứ mà hầu hết PC chơi game không cần, tinh chỉnh cài đặt cho game và thêm Akati OS Center: một ứng dụng cho Tăng tốc game, kiểm tra sức khỏe máy, ứng dụng game, tinh chỉnh và giao diện Windows, bằng tiếng Anh, Thái, Việt và Indonesia.

    Akati OS adalah playbook gaming gratis untuk AME Wizard. Playbook adalah paket skrip dan pengaturan yang diterapkan AME Wizard ke Windows yang sudah terpasang. Akati OS mematikan hal-hal yang tidak dibutuhkan kebanyakan PC gaming, menyetel pengaturan untuk game, dan menambahkan Akati OS Center: satu aplikasi untuk Game Boost, cek kesehatan PC, aplikasi gaming, tweak, dan tampilan Windows, dalam bahasa Inggris, Thai, Vietnam, dan Indonesia.

    Line endingsการขึ้นบรรทัดใหม่ (line endings)Kết thúc dòngAkhir baris (line endings)

    Files in src/ and src-win10/ must keep CRLF line endings. .gitattributes stores them exactly as they are (-text, no conversion), and the build warns about any .yml, .conf, .ps1, .cmd, .reg or similar file with LF endings. Use an editor that keeps CRLF. Elsewhere, .sh, tools/*.py and .github/ files use LF.

    ไฟล์ใน src/ และ src-win10/ ต้องขึ้นบรรทัดใหม่แบบ CRLF เสมอ .gitattributes เก็บไฟล์เหล่านี้ตามจริงทุกไบต์ (-text ไม่แปลง) และตอน build จะเตือนถ้ามีไฟล์ .yml, .conf, .ps1, .cmd, .reg หรือไฟล์ประเภทเดียวกันที่เป็น LF ควรใช้โปรแกรมแก้ไขที่คง CRLF ไว้ ส่วนไฟล์ .sh, tools/*.py และ .github/ ใช้ LF

    Các tệp trong src/ và src-win10/ phải giữ kết thúc dòng CRLF. .gitattributes lưu chúng nguyên trạng (-text, không chuyển đổi), và bước build cảnh báo mọi tệp .yml, .conf, .ps1, .cmd, .reg hoặc tương tự có kết thúc LF. Hãy dùng trình soạn thảo giữ nguyên CRLF. Ở những nơi khác, tệp .sh, tools/*.py và .github/ dùng LF.

    File di src/ dan src-win10/ harus tetap memakai akhir baris CRLF. .gitattributes menyimpannya apa adanya (-text, tanpa konversi), dan build memperingatkan setiap file .yml, .conf, .ps1, .cmd, .reg, atau sejenisnya yang memakai LF. Gunakan editor yang mempertahankan CRLF. Di tempat lain, file .sh, tools/*.py, dan .github/ memakai LF.

    Report a bug or an ideaแจ้งบั๊กหรือเสนอไอเดียBáo lỗi hoặc đề xuất ý tưởngLaporkan bug atau ide

    Open a new issue and pick a form. Bug report asks for your Windows, the Akati OS version (Akati OS Center > About) and where it happened, and for the problem report .zip (About > Create problem report). Idea asks what it should do and for which game or situation. Both forms are in English and Thai. Before reporting a setup problem, test in a VM and add the AME Wizard logs from C:\ProgramData\AME\Logs.

    เปิด issue ใหม่ แล้วเลือกฟอร์ม Bug report จะถาม Windows ที่ใช้ เวอร์ชัน Akati OS (Akati OS Center > เกี่ยวกับ) และเกิดตอนไหน พร้อมให้แนบไฟล์ .zip จาก เกี่ยวกับ > สร้างรายงานปัญหา ส่วน Idea จะถามว่าอยากให้ทำอะไร ใช้กับเกมหรือสถานการณ์ไหน ฟอร์มมีทั้งภาษาอังกฤษและไทย ถ้าเป็นปัญหาตอนติดตั้ง ให้ลองใน VM และแนบ log ของ AME Wizard จาก C:\ProgramData\AME\Logs ด้วย

    Mở một issue mới và chọn mẫu. Bug report hỏi Windows bạn dùng, phiên bản Akati OS (Akati OS Center > Giới thiệu), lỗi xảy ra ở đâu, và tệp .zip báo cáo sự cố (Giới thiệu > Tạo báo cáo sự cố). Idea hỏi tính năng nên làm gì và cho game hay tình huống nào. Cả hai mẫu bằng tiếng Anh và tiếng Thái. Trước khi báo lỗi cài đặt, hãy thử trong máy ảo và đính kèm log AME Wizard từ C:\ProgramData\AME\Logs.

    Buka issue baru lalu pilih formulir. Bug report menanyakan Windows Anda, versi Akati OS (Akati OS Center > Tentang), di mana masalah terjadi, dan file .zip laporan masalah (Tentang > Buat laporan masalah). Idea menanyakan apa yang seharusnya dilakukan dan untuk game atau situasi apa. Kedua formulir dalam bahasa Inggris dan Thai. Sebelum melaporkan masalah instalasi, uji di VM dan sertakan log AME Wizard dari C:\ProgramData\AME\Logs.
