Akati OS

A free gaming playbook for AME Wizard. Fewer things running in the background, settings tuned for games, and Akati OS Center: one app for game boost, health checks, gaming apps and the look of Windows.

Playbook สำหรับเล่นเกม ใช้กับ AME Wizard ฟรี ลดสิ่งที่ทำงานเบื้องหลัง ตั้งค่าให้เหมาะกับเกม และมี Akati OS Center แอปเดียวที่รวมบูสต์เกม ตรวจสุขภาพเครื่อง แอปเกม และหน้าตา Windows

Playbook chơi game miễn phí cho AME Wizard. Ít thứ chạy nền hơn, cài đặt tối ưu cho game, và Akati OS Center: một ứng dụng cho tăng tốc game, kiểm tra sức khỏe máy, ứng dụng chơi game và giao diện Windows.

Playbook gaming gratis untuk AME Wizard. Lebih sedikit proses di latar belakang, pengaturan yang disetel untuk game, dan Akati OS Center: satu aplikasi untuk Game Boost, cek kesehatan PC, aplikasi gaming, dan tampilan Windows.

Game Boost

  1. Update Windows and back up

    อัปเดต Windows และสำรองไฟล์

    Cập nhật Windows và sao lưu

    Perbarui Windows dan cadangkan file

    Install all Windows updates and restart: AME Wizard checks that no updates are waiting. Copy your files to another drive or to the cloud.

    ติดตั้งอัปเดต Windows ให้ครบแล้วรีสตาร์ท เพราะ AME Wizard จะตรวจว่าไม่มีอัปเดตค้างอยู่ จากนั้นก๊อปไฟล์สำคัญไปเก็บไว้ในไดรฟ์อื่นหรือบนคลาวด์

    Cài hết các bản cập nhật Windows rồi khởi động lại: AME Wizard sẽ kiểm tra để chắc chắn không còn bản cập nhật nào đang chờ. Chép tệp của bạn sang ổ khác hoặc lên đám mây.

    Instal semua pembaruan Windows lalu restart: AME Wizard memeriksa bahwa tidak ada pembaruan yang menunggu. Salin file Anda ke drive lain atau ke cloud.

    ที่ GitHub Releases (หรือปุ่มด้านบนสุด) โหลด AkatiOS-Win11_v…apbx สำหรับ Windows 11 หรือ AkatiOS-Win10_v…apbx สำหรับ Windows 10 22H2 พร้อมไฟล์ SHA256SUMS.txt

    Từ GitHub Releases (hoặc các nút ở đầu trang), tải AkatiOS-Win11_v…apbx cho Windows 11 hoặc AkatiOS-Win10_v…apbx cho Windows 10 22H2, cùng với SHA256SUMS.txt.

    Dari GitHub Releases (atau tombol di bagian atas), unduh AkatiOS-Win11_v…apbx untuk Windows 11 atau AkatiOS-Win10_v…apbx untuk Windows 10 22H2, serta SHA256SUMS.txt.

  3. Check the SHA256

    ตรวจ SHA256

    Kiểm tra SHA256

    Cek SHA256

    Open PowerShell in the download folder and run this, with the name of your file:

    เปิด PowerShell ในโฟลเดอร์ที่โหลดไฟล์ไว้ แล้วรันคำสั่งนี้ (เปลี่ยนเป็นชื่อไฟล์ของคุณ)

    Mở PowerShell trong thư mục chứa tệp đã tải và chạy lệnh sau, thay bằng tên tệp của bạn:

    Buka PowerShell di folder unduhan lalu jalankan ini, dengan nama file Anda:

    (Get-FileHash .\AkatiOS-Win11_v1.8.0.apbx -Algorithm SHA256).Hash.ToLower()
Get-Content .\SHA256SUMS.txt

    The two values must match. Do not use a file that does not match.

    ค่าทั้งสองต้องตรงกัน ถ้าไม่ตรงอย่าใช้ไฟล์นั้น

    Hai giá trị phải trùng khớp. Đừng dùng tệp không khớp.

    Kedua nilai harus sama. Jangan pakai file yang tidak cocok.

    ลากไฟล์ .apbx เข้า AME Wizard

    Seret .apbx ke AME Wizard

    "Unverified" is normal (see the FAQ). With the wrong file it says "This Windows build is not supported by this Playbook": nothing is changed, use the other file.

    ถ้าขึ้นว่า "Unverified" ถือว่าปกติ (ดูคำถามที่พบบ่อย) ถ้าใช้ผิดไฟล์จะขึ้นว่า "This Windows build is not supported by this Playbook" ไม่มีอะไรถูกเปลี่ยน ให้ใช้อีกไฟล์แทน

    "Unverified" là bình thường (xem FAQ). Nếu dùng sai tệp, nó báo "This Windows build is not supported by this Playbook": không có gì bị thay đổi, hãy dùng tệp còn lại.

    "Unverified" itu normal (lihat FAQ). Jika filenya salah, muncul "This Windows build is not supported by this Playbook": tidak ada yang diubah, pakai file yang satunya.

  6. Do what AME Wizard asks

    ทำตามที่ AME Wizard บอก

    Làm theo yêu cầu của AME Wizard

    Ikuti permintaan AME Wizard

    Before it starts, AME Wizard lists what it needs, for example Defender turned off, internet and power plugged in. Follow what it shows.

    ก่อนเริ่ม AME Wizard จะบอกสิ่งที่ต้องทำ เช่น ปิด Defender ต่ออินเทอร์เน็ต และเสียบสายชาร์จ ทำตามที่ขึ้นบนหน้าจอได้เลย

    Trước khi bắt đầu, AME Wizard liệt kê những gì cần có, ví dụ tắt Defender, có Internet và cắm sạc. Hãy làm theo những gì nó hiển thị.

    Sebelum mulai, AME Wizard menampilkan apa yang dibutuhkan, misalnya Defender dimatikan, internet, dan listrik tersambung. Ikuti yang ditampilkan.

  7. Pick your options

    เลือกตัวเลือก

    Chọn các tùy chọn

    Pilih opsi

    The recommended defaults are a good start. If you play anti-cheat games (Valorant, FACEIT), keep Defender enabled and leave "Disable Core Isolation" unticked. "Learn more" opens the options guide; most options can be changed later in Akati OS Center > Tweaks.

    ใช้ค่าแนะนำก็เริ่มต้นได้ดีแล้ว ถ้าเล่นเกมที่มีแอนตี้ชีต (Valorant, FACEIT) ให้เปิด Defender ไว้และไม่ต้องติ๊ก "Disable Core Isolation" ปุ่ม "Learn more" จะเปิดคู่มือตัวเลือก ตัวเลือกส่วนใหญ่เปลี่ยนทีหลังได้ใน Akati OS Center > ปรับแต่ง

    Các giá trị mặc định được đề xuất là khởi đầu tốt. Nếu bạn chơi game có chống gian lận (Valorant, FACEIT), hãy giữ Defender bật và đừng tích "Disable Core Isolation". "Learn more" mở hướng dẫn tùy chọn; hầu hết tùy chọn có thể đổi sau trong Akati OS Center > Tinh chỉnh.

    Pengaturan bawaan yang disarankan sudah jadi awal yang baik. Jika Anda main game dengan anti-cheat (Valorant, FACEIT), biarkan Defender aktif dan jangan centang "Disable Core Isolation". "Learn more" membuka panduan opsi; sebagian besar opsi bisa diubah nanti di Akati OS Center > Tweak.

  8. Wait, then restart

    รอจนเสร็จแล้วรีสตาร์ท

    Chờ rồi khởi động lại

    Tunggu, lalu restart

    Do not turn off the PC while it works. AME Wizard estimates about 15 minutes. The PC restarts when it is done.

    ห้ามปิดเครื่องระหว่างติดตั้ง AME Wizard ประมาณเวลาไว้ราว 15 นาที เสร็จแล้วเครื่องจะรีสตาร์ทเอง

    Đừng tắt máy khi đang cài. AME Wizard ước tính khoảng 15 phút. Máy sẽ khởi động lại khi xong.

    Jangan matikan PC selama proses berjalan. AME Wizard memperkirakan sekitar 15 menit. PC akan restart setelah selesai.

  9. Open Akati OS Center

    เปิด Akati OS Center

    Mở Akati OS Center

    Buka Akati OS Center

    After the restart, open Akati OS Center from the desktop or the Start menu. The first time, a welcome screen asks for your language, gaming apps and theme.

    หลังรีสตาร์ท เปิด Akati OS Center จากเดสก์ท็อปหรือ Start menu ครั้งแรกจะมีหน้าต้อนรับให้เลือกภาษา แอปเกม และธีม

    Sau khi khởi động lại, mở Akati OS Center từ màn hình nền hoặc menu Start. Lần đầu tiên, màn hình chào mừng sẽ hỏi ngôn ngữ, ứng dụng chơi game và giao diện.

    Setelah restart, buka Akati OS Center dari desktop atau menu Start. Pertama kali dibuka, layar sambutan menanyakan bahasa, aplikasi gaming, dan tema Anda.

Windows, AtlasOS, dan Akati OS

Features only, no speed claims. Akati OS is built on AtlasOS: its tweaks are the work of the AtlasOS team.

How do I go back to normal Windows?จะกลับไปใช้ Windows ปกติได้อย่างไรLàm sao để quay lại Windows bình thường?Bagaimana cara kembali ke Windows biasa?

A playbook cannot be fully undone: to go back to normal Windows, reinstall Windows. That is why you should back up first and try it in a virtual machine. Single changes can be turned back in Akati OS Center: every tweak shows what it changes, and the change history has Undo.

playbook ย้อนกลับไม่ได้ทั้งหมด ถ้าจะกลับไปเป็น Windows ปกติต้องลง Windows ใหม่ จึงควรสำรองไฟล์และลองใน VM ก่อน ส่วนการปรับแต่งทีละอย่างปรับกลับได้ใน Akati OS Center ทุกสวิตช์บอกว่าเปลี่ยนอะไร และมีประวัติการเปลี่ยนแปลงพร้อมปุ่มเลิกทำ
