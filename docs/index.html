Game boost switches to a performance power plan, closes background apps, turns notifications off and frees standby RAM. Stop puts everything back. It can start by itself when a game from My games opens.

บูสต์เกมจะเปลี่ยนไปใช้แผนพลังงานแรงสุด ปิดแอปเบื้องหลัง ปิดการแจ้งเตือน และคืน RAM ที่ค้างอยู่ กดหยุดเมื่อไรทุกอย่างก็กลับเหมือนเดิม และเริ่มเองได้เมื่อเปิดเกมที่อยู่ใน “เกมของฉัน”

Tăng tốc game chuyển sang gói nguồn hiệu năng cao, đóng ứng dụng nền, tắt thông báo và giải phóng RAM chờ. Dừng là mọi thứ trở lại như cũ. Nó có thể tự bật khi một game trong Game của tôi được mở.

Game Boost beralih ke power plan performa, menutup aplikasi latar belakang, mematikan notifikasi, dan membebaskan RAM standby. Stop mengembalikan semuanya. Bisa menyala sendiri saat game dari Game saya dibuka.
